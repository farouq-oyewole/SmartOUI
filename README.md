# 📦 SmartOUI

SmartOUI is a modern Flutter web app designed specifically for **Oduduwa University students** to:

- 💳 Make secure payments for tuition, fees, and other charges  
- 🧾 Instantly generate and download detailed receipts with QR codes  
- 📊 View payment history and track wallet balance  
- 🔒 Store all transactions securely using Firebase
